# Créditos — Pinball Las Vegas

O arquivo `pinball.html` incorpora o jogo **Space Cadet — 3D Pinball**, de Nipun Batra, publicado em:

- Projeto original: https://github.com/nipunbatra/pinball
- Versão original online: https://nipunbatra.github.io/pinball/

O README do projeto original declara licença MIT. O jogo foi mantido como jogo de arcade independente; sua pontuação não altera a carteira nem representa saldo ou prêmio em dinheiro. O título visível no site foi adaptado para “Pinball Las Vegas”; a tela “About” interna mantém a referência ao tributo original.
